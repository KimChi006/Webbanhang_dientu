# Kịch bản bảo vệ (5–7 phút)

1. Giới thiệu: TechStore là website tĩnh HTML/CSS/JS; dữ liệu nghiệp vụ dùng Local Storage. Danh mục chuẩn có 120 sản phẩm/7 loại.
2. Trang khách: tìm không dấu, chọn Laptop, chọn nhiều hãng/GPU, sắp xếp giá, sang trang rồi đổi bộ lọc để thấy quay về trang 1. Dùng Back/Forward để minh họa URL.
3. Mở chi tiết, thêm giỏ, đổi số lượng; nêu kiểm tra tồn và giá chốt.
4. Đăng nhập khách demo, tạo đơn thử, xem lịch sử; không trình bày thanh toán như giao dịch thật.
5. Mở Admin: đăng nhập, xem sản phẩm/danh mục, tạo phiếu nhập nháp rồi hoàn thành để minh họa tồn, giá vốn và giá bán.
6. Mở Đơn hàng, chuyển luồng Mới đặt → Đã xử lý → Đã giao và nêu xuất kho chỉ một lần.
7. Kết: import batch idempotent, migration giữ ảnh Admin tùy chỉnh, sao lưu/khôi phục và test tự động/browser.
